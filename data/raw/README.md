# Original downloads

These files were downloaded from links in the public ASDMotion repository. Preserve them unchanged. `manifest.json` records file IDs, retrieval/check timestamps, byte lengths and SHA-256 hashes. Hashes are locally computed integrity checks, not upstream-supplied signatures.

- dataset.pkl: labeled selected skeleton clips.
- asdpose.zip: continuous skeleton archive plus db.csv; README describes it as unannotated.
- model.pth: checkpoint preserved without execution/deserialization.

The code repository has an MIT license. The paper is CC BY; Supplement 2 states data are accessible online for everyone/any analysis purpose. Do not automatically treat the code license as a separately verified dataset redistribution license. No raw RGB video was obtained.
